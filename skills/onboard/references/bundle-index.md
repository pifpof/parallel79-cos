# Memory

This folder is an Open Knowledge Format (v0.2) bundle. The full map, with when to open each folder, is the router: [memory.md](../memory.md).

## Folders

- [Profile](./profile/index.md): Who the executive is: about, priorities, workflows, key people, working style, the wishlist.
- [Projects](./projects/index.md): One file per project or initiative, each with a next: line and a Decisions section.
- [Library](./library/index.md): Retained knowledge, research, captured sources, the decisions log.
- [Reference](./reference/index.md): System settings used by the skills.

## System files

- [Hot-state card](./_state.md): What matters right now. Derived from the files, rebuildable.
